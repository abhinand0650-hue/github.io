# Abhinand — Personal Portfolio

A responsive, static personal portfolio website built with HTML, CSS and vanilla JavaScript. It is designed to deploy free on GitHub Pages.

## Before publishing

1. Open `index.html`.
2. Replace `hello@example.com` with your real email address in the `mailto:` link.
3. Update any role titles, dates or project descriptions that need correction.
4. Add your own project links or photographs if you want them included.

## Publish free with GitHub Pages

1. Sign in to https://github.com/ or create a free account.
2. Create a new **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html`, `style.css`, `script.js` and this `README.md` to the repository root.
4. Open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait a few minutes and visit `https://YOUR-GITHUB-USERNAME.github.io`.

GitHub Pages supports free hosting for public repositories. A custom domain is optional and generally costs money; the GitHub Pages address is free.

## Files

- `index.html` — page content and sections
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation and scroll reveal effects
